# CEN 4802 Java Web Application

## Author
Brianna Allen

## Description
This project is a Java web application created for a previouos course COP3330. The application provides a greeting form that allows a user to enter a student ID, date information, and a message. The application processes the submitted information and generates a greeting for the user.

The application runs locally and can be accessed through a web browser. It will serve as the foundation for future assignments involving version control, testing, building, deployment, and other DevOps practices throughout the course.
